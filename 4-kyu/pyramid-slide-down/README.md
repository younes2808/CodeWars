<h2><a href=https://www.codewars.com/kata/551f23362ff852e2ab000037/train/csharp/69a994c661adca0182190b5c target="_blank">Pyramid Slide Down</a></h2><h3>4 kyu</h3><h3 id="lyrics">Lyrics...</h3><p>Pyramids are amazing! Both in architectural and mathematical sense. If you have a computer, you can mess with pyramids even if you are not in Egypt at the time. For example, let's consider the following problem: imagine that you have a pyramid built of numbers, like the ones here:</p><pre style="font-size:125%;line-height:150%">    <span style="color:red">3</span>                <span style="color:red">10</span>   <span style="color:red">7</span> 4             10  <span style="color:red">20</span>  2 <span style="color:red">4</span> 6          10  <span style="color:red">10</span>  20 8 5 <span style="color:red">9</span> 3       10  <span style="color:red">90</span>  10  20</pre><h3 id="here-comes-the-task">Here comes the task...</h3><p>Let's say that the <em>'slide down'</em> is the maximum sum of consecutive numbers from the top to the bottom of the pyramid. As you can see, the largest <em>'slide downs'</em> are <code>3 + 7 + 4 + 9 = 23</code>, and <code>10 + 20 + 10 + 90 = 130</code>.</p><p>Your task is to write a function that takes a pyramid representation as an argument and returns its <strong>largest</strong> <em>'slide down'</em>. For example:</p><ul><li>With the input <code>[[3], [7, 4], [2, 4, 6], [8, 5, 9, 3]]</code>, your function should return <code>23</code>.</li><li>With the input <code>[[10], [10, 20], [10, 10, 20], [10, 90, 10, 20]]</code>, your function should return <code>130</code>.</li></ul><h3 id="by-the-way">By the way...</h3><p>Tests include some extraordinarily high pyramids so as you can guess, brute-force method is a bad idea unless you have a few centuries to waste. You must come up with something more clever than that.</p><p>(c) This task is a lyrical version of <strong>Problem 18</strong> and/or <strong>Problem 67</strong> on <a href="https://projecteuler.net" data-turbolinks="false" target="_blank">ProjectEuler</a>.</p>
